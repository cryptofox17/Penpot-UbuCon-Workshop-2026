This repository contains the starter file for the Getting Started with Penpot hands-on workshop happening in UbuCon India 2026.

You'll use this file to learn the basics of Penpot through practical design activities.

## Getting Started

### 1. Download the starter file

Download the starter file from this repository:

1. Open the starter file in the repository.
2. Click **Download raw file** or **Download**.
3. Save the file to your computer.

### 2. Open Penpot

Open [Penpot](https://penpot.app/) in your browser and sign in or create an account if needed.

### 3. Import the starter file

1. Open your Penpot workspace.
2. Use Penpot's import option to import the downloaded starter file.
<img width="2540" height="1448" alt="how to import" src="https://github.com/user-attachments/assets/1d488965-3332-4bb4-a185-990f11fecfc2" />
